Dropdown select. Compose `<Select>` with a `<SelectTrigger><SelectValue placeholder="…" /></SelectTrigger>` and a `<SelectContent>` holding `<SelectItem value="…">` (optionally grouped with `<SelectGroup>` / `<SelectLabel>` and divided with `<SelectSeparator>`). Control the value with `value` + `onValueChange`.
