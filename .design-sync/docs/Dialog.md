Modal dialog with a dimmed overlay. Compose `<Dialog>` with a `<DialogTrigger asChild>` (usually a Button) and a `<DialogContent>` containing `<DialogHeader><DialogTitle/><DialogDescription/></DialogHeader>`, body content, and a `<DialogFooter>` of actions. Control open state with `open` + `onOpenChange` when needed.
